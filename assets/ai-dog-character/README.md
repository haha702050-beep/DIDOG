# AI Dog Character Asset Pack

## Character Concept

Original AI anime mascot dog. The design uses broad friendly future-companion cues: blue-white rounded body, floppy dog ears, paw pads, golden bell collar, and a small utility chest pocket. It is intended as an original dog character, not a copy of any existing copyrighted mascot.

Working name: LanDou AI Dog

## Prompt Notes

The image generation used an original mascot prompt with these constraints:

- Create a cute futuristic robotic dog character.
- Use blue-white body language, round friendly forms, floppy ears, paw pads, a bell collar, and a small utility pocket.
- Keep it clearly dog-like and distinct from any existing copyrighted mascot.
- Avoid cat traits, whiskers, red round nose, copied silhouette, logos, readable text, and watermarks.

## Production Notes

Generated with the built-in image generation tool. The MP4 was assembled locally from PNG frames using a small Swift/AVFoundation encoder at `tools/encode_image_sequence.swift`.
